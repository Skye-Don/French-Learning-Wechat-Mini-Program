# 微信小程序上传与发布指南（AppID: wx290524b33830af1f）

> 状态：代码侧已全部配好，只差你本人在微信开发者工具里点两下 + 扫码。
> 规则表述一律**以微信官方最新审核规范与开发者工具实际界面为准**，本文只给操作路径与坑位。

---

## 0. 为什么必须你自己点"上传"

小程序的代码上传链路是：

```
开发者工具 ──(HTTPS)──> 微信后台 ──校验──> 该 AppID 下的开发者/体验成员
```

上传时必须用**绑定在该 AppID 下的开发者微信号扫码授权**。这属于你账号的私有凭据，**任何第三方（包括我）都无法代持，也没有 CLI 能绕过扫码**。
替代方案只有官方的 [miniprogram-ci](https://developers.weixin.qq.com/miniprogram/dev/devtools/ci.html)（需你在 mp 后台生成**上传密钥**并把私钥文件放到 CI 环境），如果你要走自动化发布，可以让我按 ci 的方式再改造一版。

我已经做完的部分：AppID 写入配置、目录结构对齐、页面/样式/接口全部就绪，导入即可预览。

## 1. 导入项目（2 分钟）

1. 打开**微信开发者工具**（建议稳定版 Stable Build，版本以官网为准）→ 左侧选「小程序」
2. 点「+」新建项目 → 选「导入项目」
3. **目录**选本仓库的 `miniprogram/`（⚠️ 选这一层，不要选仓库根目录；`project.config.json` 在这一层）
4. AppID 选「使用测试号」旁边切换成**填入你的 AppID**：`wx290524b33830af1f`（配置里已写死，导入后会自动带出）
5. 点「确定」

导入后应该能看到首页渲染出来（首页会尝试静默登录，后端不通时会走兜底，不影响看界面）。

### 导入后立刻检查这 3 项

| 检查项 | 位置 | 期望 |
|---|---|---|
| AppID 正确 | 开发者工具右上角「详情 → 基本信息」 | `wx290524b33830af1f` |
| 调试基础库 | 「详情 → 本地设置」 | 用一个较新的 3.x（越高覆盖越广，最低版本要你在 mp 后台设） |
| 不校验合法域名 | 「详情 → 本地设置」 | **本地调试阶段勾上**；正式版前必须取消并配好域名 |

## 2. 后端域名（发布前必做，否则线上请求全失败）

`miniprogram/utils/config.js` 里现在是这样：

```js
const PROD_BASE_URL = "";                                            // ← 上线前填你的域名
const DEMO_BASE_URL = "https://french-learning-miniapp.app.workbuddy.host";
```

要做两件事：

1. **把 `PROD_BASE_URL` 换成你自己的后端域名**（HTTPS，且已完成 ICP 备案）
2. **在 mp 后台配 request 合法域名**：
   `mp.weixin.qq.com → 开发管理 → 开发设置 → 服务器域名 → request 合法域名`
   加上你的域名。修改后**需要重新上传代码才生效**。

> ⚠️ `DEMO_BASE_URL` 是本次交付附带的临时预览环境，**不承诺可用性、不可用于线上**，仅用于"先跑通看效果"。
> ⚠️ 域名是否需要 ICP 备案、是否支持非备案域名，以微信官方最新规则为准；不确定就先在 mp 后台点一次"添加"看它给什么提示。

### 后端怎么起

生产后端在 `backend/`（FastAPI + PostgreSQL + Redis）：

```bash
cd backend
cp .env.example .env          # 填 AppID / AppSecret / JWT_SECRET / 数据库串
pip install -r requirements.txt
alembic upgrade head          # 建表（含 0002 难度改 CEFR）
python ../scripts/import_seed.py    # 导 41 张种子卡
python ../scripts/create_admin.py   # 建后台管理员
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

或用 Docker：`docker/docker-compose.yml`（含 Postgres + Redis + API + Nginx）。

## 3. 上传代码

1. 开发者工具右上角 **「上传」**
2. 填**版本号**（建议 `0.1.0`）与**项目备注**（如 `V0 首版：等级-课时-闪卡-打卡`）
3. 扫码确认 → 上传成功

上传后代码进入**开发版**（只有开发者和体验成员能看）。

---

## 4. 体验版 → 提交审核

1. `mp.weixin.qq.com → 管理 → 版本管理`，把刚上传的版本设为**体验版**
2. 在「成员管理」里把测试同学加为**体验成员**，让他们扫码验收
3. 验收通过后回到版本管理 → **提交审核**

### 提审前自查（缺一项就大概率被驳回）

- [ ] **类目**：选对类目（教育 / 工具等）。教育类目是否需要资质，**以微信官方最新类目资质要求为准**，不确定先在 mp 后台看类目详情页的提示
- [ ] **用户协议 + 隐私指引**：mp 后台「设置 → 基本设置 → 用户隐私保护指引」必须配置并生效
  - 本项目用到 `wx.login`（换取 openid），属于**用户信息收集**，隐私指引里必须声明
  - V0 未接录音/位置/相册，若后续加跟读打分（录音权限），必须同步更新隐私指引
- [ ] **测试账号**：审核员要能进得去。V0 是静默登录，无账号体系，备注里写清楚"无需注册，打开即用"
- [ ] **内容合规**：41 张种子卡里有 2 张脏话卡（如 putain），走 `sensitive_opt_in` 默认隐藏机制；审核备注里说明"敏感内容默认不展示，需用户主动开启"，避免被判违规内容
- [ ] **无外链、无诱导分享、无强制关注**
- [ ] **页面路径可全部打开**：10 个页面都点一遍，不能有白屏/报错

## 5. 常见坑

| 现象 | 原因 | 处理 |
|---|---|---|
| 预览白屏 | 后端不通 + 页面没兜底 | 看控制台；确认 `API_BASE_URL` 与域名白名单 |
| 真机请求失败，模拟器正常 | 真机**强制校验**合法域名 | 配 request 合法域名后重新上传 |
| 上传按钮灰掉 | 当前微信不是该 AppID 的开发者 | mp 后台「成员管理」把自己加为开发者 |
| 提示"包体积超限" | 主包 > 2MB | V0 只有 10 个页面，远未到阈值；后续膨胀再拆分包 |
| 审核说"服务不可用" | 后端域名挂了或 HTTPS 证书有问题 | 先在体验版让审核路径能走通 |
